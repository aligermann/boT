# ربات مدیریت فایل تلگرام (Python)

نسخه پایتون کامل از سورس Cloudflare Workers با تمام قابلیت‌ها + دکمه‌های رنگی (Bot API 9.4).

## ویژگی‌ها

- آپلود تکی و گروهی فایل با لینک اختصاصی
- عضویت اجباری در کانال‌ها
- قفل واکنش (ریکشن)
- مدیریت ادمین‌ها با نقش‌های owner / full / uploader
- ارسال پیام همگانی
- آمار کاربران
- حذف خودکار فایل‌ها بعد از ۳۰ ثانیه
- دکمه‌های رنگی شیشه‌ای: primary (آبی)، success (سبز)، danger (قرمز)

## متغیرهای محیطی

| متغیر       | توضیح                          | پیش‌فرض (داخل کد) |
|-------------|--------------------------------|-------------------|
| BOT_TOKEN   | توکن ربات از BotFather         | قرار داده شده     |
| MAIN_ADMIN  | آیدی عددی ادمین اصلی           | 7764565509        |
| DB_PATH     | مسیر فایل SQLite               | bot_data.db       |

## راه‌اندازی روی Railway (رایگان)

1. اکانت Railway بسازید و به GitHub وصل کنید.
2. ریپوی این پروژه را Push کنید یا ZIP را آپلود کنید.
3. در Railway یک New Project → Deploy from GitHub / Empty → Upload.
4. متغیرهای محیطی را اضافه کنید (اختیاری چون داخل کد هست):
   - `BOT_TOKEN` = توکن ربات
   - `MAIN_ADMIN` = 7764565509
5. Deploy کنید. نوع سرویس: Worker یا Web (polling نیاز به پورت ندارد).
6. لاگ‌ها را چک کنید تا ببینید Bot starting with polling ظاهر شده.

### دستورات محلی برای تست

```bash
pip install -r requirements.txt

```

## نکات مهم

- ربات با long polling کار می‌کند (مناسب Railway رایگان).
- دیتابیس SQLite است و در همان کانتینر ذخیره می‌شود (برای production بهتر است volume یا Postgres اضافه کنید).
- برای کانال‌های عضویت اجباری، ربات را ادمین کانال کنید.
- دکمه‌های رنگی فقط در نسخه‌های جدید تلگرام (بعد از فوریه ۲۰۲۶) نمایش داده می‌شوند.

توکن و آیدی ادمین از قبل داخل سورس قرار داده شده‌اند.
